# 🏝️ جزيرة الأطفال | متجر ألعاب الأطفال في القصيم

موقع متجر ألعاب الأطفال **جزيرة الأطفال** في القصيم (بريدة) — تصميم عربي كامل (RTL) بألوان مرحة، ومتجاوب مع الجوال.

## ✨ المميزات
- 🧸 قائمة ألعاب بالصور الحقيقية، مصنفة حسب العمر مع الأسعار بالريال
- 🔍 بحث وفلترة حسب العمر والتصنيف والسعر
- 🛒 سلة تسوق + إتمام الطلب عبر واتساب
- 💳 قسم طرق الدفع (مدى، Apple Pay، تابي وتمارا، عند الاستلام)
- 📍 العنوان + معلومات المتجر + آراء الأهالي

## 🚀 التشغيل
افتح ملف `index.html` في المتصفح مباشرة — لا يحتاج أي تثبيت.

## ⚙️ الإعدادات
- رقم الواتساب: ابحث عن `WHATSAPP_NUMBER` داخل `index.html`
- الصور: داخل مجلد `images/` (مصدرها Unsplash 📷)

الموقع منشور على GitHub Pages.
